name: what
description: Re-explain your last reply in plain English.
disable-model-invocation: true
---

Restate your last reply so the user understands it on first read. Open with a
one-sentence gist and keep the whole restatement shorter than the original. Use
plain words, and add the background the original assumed the user had. When a
term has to stay, such as a file, command, or API name, define it inline the
first time. Restate only: no new information, actions, or follow-up question.

If the user passed arguments, treat them as the part of the reply to explain.
